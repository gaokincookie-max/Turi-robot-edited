# VOID ANGLER Layout Editor v1

ゲーム本体とは分離した、レイアウト調整専用Webツールです。

## 起動
`index.html` をブラウザで開いてください。GitHub Pages / Netlify Drop にそのまま置いても動きます。

## 対応シーン
- 戦闘：味方艦（Mk1〜4）
- 戦闘：敵艦（Mk1〜4）
- 整備：機体（Mk1〜4）
- 整備：釣具

## 操作
- パーツをドラッグ：移動
- 右下の黄色ハンドルをドラッグ：大きさ変更
- 右ペイン：X/Y、幅/高さ、角度、拡大率、反転、Z順、透明度を数値調整
- グリッド / スナップ対応
- 味方→敵への上下反転コピーあり
- JSON保存 / 読込 / コピー / ダウンロード対応
- 「端末保存」で localStorage に保存

## ChatGPTへ返すとき
`JSON出力` で `void-angler-layout.json` を出し、そのファイルをチャットに添付してください。
そのJSONを基準にゲーム本体へ配置を反映できます。

## JSONの考え方
各アイテムは `x`, `y`, `w`, `h` をプレビュー領域に対する百分率で保持します。`rot` は角度、`scale` は追加倍率です。
