# VOID ANGLER Layout & Asset Editor v3

## 追加したもの
- 大きな元画像（ソースシート）を同梱
- 四角切り抜きに加えて、ブラシで比較的自由に切り抜ける「自由切り抜き」機能
- 切り抜き後のアセットを独立素材として複製作成する機能

## 使い方
1. 左の一覧で `sheet` カテゴリの大きな元画像を選ぶ
2. 上段の大画像で、まず大まかな四角切り抜きを作る
3. 右下の「自由切り抜き編集」で、不要部分をブラシで消す / 戻す
4. 必要なら Anchor / Mount / Muzzle を指定する
5. 「切り抜き版を複製作成」で独立アセットにする
6. レイアウト調整タブで配置を詰める

## 用語
- A = Anchor（配置基準点）
- M = Mount（接続点）
- T = Tip / Muzzle（先端・銃口）

## 補足
- JSON保存 / 読込に対応
- 端末保存にも対応
- 自由切り抜きは、厳密なベクター切り抜きではなく、ブラシで透明化する方式です
