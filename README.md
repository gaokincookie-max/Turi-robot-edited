# VOID ANGLER Layout & Asset Editor v2

## できること
- アセットの切り抜き、透明余白トリム、アンカー/接続点/銃口位置の調整
- 切り抜き版アセットの複製作成とPNG保存
- 場面ごとのレイアウト調整（戦闘:味方、戦闘:敵、整備:機体、整備:釣具）
- ドラッグ移動、サイズ調整、角度/反転/透明度/Z順の編集
- JSON保存/読込、端末保存

## 使い方のおすすめ
1. まず「アセット調整」で余白をトリムし、Anchor/Mount/Muzzle を整える。
2. 必要なら「切り抜き版を複製作成」で扱いやすい派生アセットを作る。
3. 次に「レイアウト調整」で位置・大きさ・角度を詰める。
4. 完成したら JSON を保存またはコピーして本編に反映する。

## 補足
- `bundled_assets/` に現行プロトタイプ由来の主要アセットを同梱しています。
- ユーザー画像の追加にも対応しています。
- 画像ごとに中心がズレる問題に対応するため、座標調整の前にアセット側の基準点を持てるようにしています。
